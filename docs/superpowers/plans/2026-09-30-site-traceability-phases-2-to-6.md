V is ticked only where the evidence shows the element's data or behaviour through a production path (spec 6): a staging response, a `db_query_cr.sh` result showing the rows the page needs, or a 401 that proves a permission state. Reading the code never counts.

- Every task ends by running the recipes it names and pasting their output into its report.

## Review Focus

1. A tick whose evidence does not cover the row (a T commit that did not touch the row, a V comment whose command does not show the element's data, a Te run that never executed the cited test): the checklist lies. R10 pins the format; the reviewer checks the substance on every ticked row of the task.
2. A body that credits a test with an assertion it does not make, or states a mechanism backwards: Phase 1's reviews caught both; each area review opens every cited test and at least two citations per body.
3. A V tick resting on data that exists but is not what the element renders (a table the page never reads, a stale snapshot passed off as current): the Data cell and the freshness query must name the same table and the query's timestamp must be recent enough for the page's own staleness rule.
4. A Phase 0 correction that is itself wrong (Task 14 corrected the most-active chain; the review had to verify it against the handler and the fetcher): every correction is verified against the code by the reviewer, not accepted from the report.
5. The two documents contradicting each other on the same row after an area task: R8 and the label check pin IDs and labels; the reviewer samples ten rows for content.

**R11 · headings equal Element cells and S anchors resolve (run from /home/user).**
```bash
python3 - <<'EOF'
import re,unicodedata
m=open('stocks/docs/product/03-SITE-TRACEABILITY.md',encoding='utf8').read().splitlines()
u=open('solyra/docs/UI-SCREENS.md',encoding='utf8').read().splitlines()
labels={}
for l in m:
    c=[x.strip() for x in l.split('|')]
    if len(c)>8 and re.fullmatch(r'[A-Z]+-\d{2}',c[1]) and re.fullmatch(r'\[[ x]\]',c[3]): labels[c[1]]=c[2]
heads={}
def slug(t):
    t=t.lower(); t=re.sub(r'[^\w\s-]','',t); return re.sub(r'\s','-',t)
for l in u:
    mm=re.match(r'^##### ([A-Z]+-\d{2}) · (.*)$',l)
    if mm: heads[mm.group(1)]=(mm.group(2),slug(l[6:]))
bad=[i for i,lab in labels.items() if heads.get(i,('',''))[0]!=lab]
print('label mismatches:',bad)
anch=set(v[1] for v in heads.values())
miss=[]
for l in m:
    for a in re.findall(r'UI-SCREENS\.md#([a-z0-9-]+)\)',l):
        if a not in anch and not a.startswith('screen-') and not a.startswith('00--') and a not in ('cross-cutting-specs',): miss.append(a)
print('unresolved S anchors:',sorted(set(miss)))
EOF
```
Expected: `label mismatches: []` and `unresolved S anchors: []`.
