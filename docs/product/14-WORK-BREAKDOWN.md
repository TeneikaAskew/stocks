## Task template

EPIC → capability → feature ID → SHALL requirement → issue (blocking or not, plus dependency)
→ origin / evolution / remediation PR → exact code path → **failing regression first** →
implementation → unit / integration / E2E / operational proof → production verification →
catalog and status update. Owner, target release, estimate and rollout stay `TBD` until assigned.
