## ERD.drawio — corruption fix + table-shape conversion

- **Date**: 2026-07-05
- **Files**: `ERD.drawio`
- **What changed**: Six edge-label `<mxCell>` elements were nested inside
  their parent edge cells with no `id` — invalid mxGraph XML that made
  drawio fail with "Could not add object for mxCell" when opening the
  Market data, Insights, and Backtest tabs. Labels were hoisted to
  sibling cells with unique ids and standard `edgeLabel` style. All 61
  entity boxes across the 6 pages were then converted from newline-text
  rectangles to real drawio table shapes: title bar, PK/UQ/FK/`-` badge
  column with a full-height divider, one row per field, italic
  writer/footer rows. Category border colors preserved; each page's
  layout reflowed downward (column-aware push-down) so nothing overlaps.
- **Why**: The nested-label corruption shipped in PR #535's hand-authored
  XML; the text-blob boxes didn't read like an ER diagram.
- **Benefit**: All tabs open cleanly; tables look and behave like tables
  (rows are selectable/editable in drawio).
