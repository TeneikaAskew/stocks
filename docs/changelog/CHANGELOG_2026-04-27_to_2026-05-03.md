### Level-Aware Trigger + Gap-Regime Gate (PR α from Hallucination Plan) — PR #136
- **Files**: `lib/agents/trade_planner.py`, `lib/agents/summarizers.py`, `lib/agents/schema.py`, `lib/agents/orchestrator.py`, `tests/test_trade_planner.py` (+11 tests)
- **What Changed**: Replaces the rigid `trigger = prior_day_high` rule with a multi-timeframe **level walk**, plus a three-tier regime classifier. **Level walk:** walks `effective_PDH → PWH → PMH → PQH → PYH` for longs (mirrored for shorts) and picks the closest UNBROKEN level as the trigger. "Cleared" uses `max(reference_price, pre_high)` so an overnight wick that touched a level still counts. **Regime classifier:** `normal` (next unbroken level within 3 ATR → standard trigger plan); `extended` (next unbroken level ≥ 3 ATR away → plan emitted, rationale recommends 15-min ORB confirmation); `orb_only` (every level in the trade direction is cleared → no targets emitted, rationale tells trader to wait for opening range). **Inside-of-inside (mother bar):** when the prior bar is a strat '1' (inside bar), the algorithm walks back through consecutive '1' bars to find the outer mother bar and uses ITS H/L as `effective_PDH/PDL`. **Side effect:** the orchestrator now uses the deterministic neutral persona plan for the headline `entry_zone`/`stop`/`targets` in `InsightReport` (was: LLM PM's free-form output). This is the original Fix A from `docs/plans/INSIGHT_ZONE_HALLUCINATION_PLAN.md` — closes the LLM hallucination surface. Persona alternatives still in `report.persona_plans`. Concrete impact on the 7 historical replays: AMD 4/23 + 4/24 → `orb_only` (was: PDH); CARS 3/31 → $8.66 (PWH; walked past PDH); ARM 4/20+4/21 → $183.16 (PYH); ARM 4/22+4/23 → `orb_only`.
- **Why**: After PR #135 fixed the tz-leak, the AMD/CARS/ARM historical replays surfaced two failure modes: (1) gap-up where pre-market cleared PDH overnight — the planner anchored entry at a level price had already left behind; (2) extreme gaps (AMD 4/24, +12%) — every structural level had been cleared overnight, no clean anchor.
- **Benefit**: Strict-strat behavior — more conservative than the old "fire on cleared PDH" approach. Trades that don't have a clean structural target get skipped or deferred to ORB confirmation. 22/22 trade-planner tests pass (11 new + 11 existing); 125/125 strat + strat_levels tests pass.

### `as_of` Timezone Leak Fix — PR #135
- **Files**: `lib/strat.py`, `tests/test_strat.py`, `docs/plans/INSIGHT_ZONE_HALLUCINATION_PLAN.md`
- **What Changed**: Fixes `compute_strat_status` silently swallowing a `TypeError` when comparing tz-naive `df.index` against a tz-aware `as_of` cutoff. Concrete failure mode (pre-fix): `lib.data_loader.load_daily()` strips timezone → `df.index.tz is None`; orchestrator passes `INSIGHT_AS_OF=2026-04-20T13:15:00Z` → tz-aware UTC; the conditional `df.index.tz is not None and cutoff.tz is None` is False (the actual situation is the opposite case — naive index, tz-aware cutoff); `df[df.index <= cutoff]` raises `TypeError: Invalid comparison between dtype=datetime64[ns] and Timestamp`; the bare `except Exception: pass` swallows it; the function continues with the **unfiltered** DataFrame → `df.iloc[-1]` is the most recent bar in the database (today, ~2026-04-27) → `trigger_high = df.iloc[-2]['High']` resolves to a **future bar's high**. Symptom: ARM 4/20 replay produced `entry_zone=$237.68-$246.32` despite the actual H/L being 175.31/164.10 — the recurring $237.68 was a number with no source in the data the LLM should have seen. Fix: handle both directions of the tz mismatch + remove the bare-except.
- **Why**: Severity HIGH — historical replays read post-`as_of` bars; the LLM literally saw the future. 5 of 7 AMD/CARS/ARM replay runs produced obviously impossible entry zones.
- **Benefit**: Replays now read only bars on or before the `as_of` timestamp. See [`docs/plans/INSIGHT_ZONE_HALLUCINATION_PLAN.md`](../plans/INSIGHT_ZONE_HALLUCINATION_PLAN.md) for the full investigation.
