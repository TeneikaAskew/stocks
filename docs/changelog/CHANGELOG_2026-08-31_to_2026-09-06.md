# Changelog: 2026-08-31 to 2026-09-06

Repository-shape week: the frontend leaves for its own repo, four retired
projects move under `archive/`, and the documentation follows the code it
describes. No trading logic changed.

## Themes this week

1. **The frontend becomes its own repo.** `platform/src` and its build
   config move to [solyra](https://github.com/TeneikaAskew/solyra); stocks
   keeps `platform/api` and serves the API. The docs describing the React

   `archive/` with their history intact.

## archive/ — four retired projects moved out of the active tree

- **Date**: 2026-09-01
- **Files**: `archive/earnings_options_analytics/`,
  `archive/google-apps-script/`, `archive/success-report-site/`,
  `archive/website/`, `.gitignore`, `.github/workflows/README.md`
- **What changed**: 115 files moved under `archive/`. Verified as an exact
  1:1 move — 115 removed, the same 115 restaged, nothing dropped and
  nothing newly tracked. Two `.gitignore` rules were needed to keep it
  faithful: the repo-root `data/` rule matched `archive/*/data/` and would
  have silently dropped ten committed fixture files while leaving them on
  disk, so a negation re-includes them; a paired rule keeps `*.csv` and
  `.clasp.json` excluded, because the live projects never tracked those.
  The five stale paths in `.github/workflows/README.md` were repointed.
- **Why**: These projects no longer feed the trading pipeline, but their
  code and history are worth keeping reachable.
- **Benefit**: The active tree only contains what still runs. Nothing was
  lost: no Python module imports them, and the workflows that once drove
  them are already fully retired.
