# Interactive Dashboard

This folder is reserved for future dashboard exports and screenshots.

## Current Dashboard

The **live interactive dashboard** is launched via:

```bash
# From earnings_options_analytics/ directory
./run_dashboard.sh
```

This opens a Streamlit web application at http://localhost:8501

## Dashboard Features

### 6 Interactive Pages:
1. 📊 **Overview** - Executive summary
2. 📈 **Strategy Performance** - Multi-strategy comparison
3. ⏰ **Earnings Timing** - Entry window optimization
4. 🎯 **Risk Management** - Position sizing & risk/reward
5. 📉 **Indicators** - Technical indicator effectiveness
6. 🔍 **Data Explorer** - Raw data browser with export
