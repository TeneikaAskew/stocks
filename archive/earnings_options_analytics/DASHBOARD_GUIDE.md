# Interactive Dashboard Guide

## Overview

The Earnings Options Analytics Dashboard provides an interactive web-based interface for exploring your trading strategy performance data.

## Features

### 📊 Six Interactive Pages

1. **Overview**
   - Executive summary with key performance metrics
   - Strategy comparison charts (4 subplots)
   - Optimal holding period visualization

2. **Strategy Performance**
   - Multi-strategy comparison tool
   - Interactive filtering by strategy
   - Hit rate and profit visualizations
   - Multi-day profitability distribution

3. **Earnings Timing**
   - Entry window performance analysis
   - Top entry days visualization
   - Pre vs Post earnings comparison
   - Interactive profit factor charts

4. **Risk Management**
   - Kelly Criterion position sizing
   - Risk/Reward distribution
   - Drawdown analysis by strategy
   - Recovery rate metrics

5. **Indicators**
   - Technical indicator correlations
   - Top 10 predictive indicators
   - Optimal indicator ranges
   - Sweet spot identification

6. **Data Explorer**
   - Browse all raw datasets
   - Column statistics
   - CSV download functionality
   - Data quality inspection

## Quick Start

### Method 1: Using the Launcher Script (Recommended)

```bash
cd earnings_options_analytics
./run_dashboard.sh
```

This will:
1. Check for Streamlit installation
2. Run analysis if no data exists
3. Launch the dashboard at http://localhost:8501

### Method 2: Manual Launch

```bash
cd earnings_options_analytics

# Ensure you have data
python earnings_options_analytics.py --export-csv

# Launch dashboard
streamlit run dashboard_app.py
```

## Dashboard Controls

### Navigation
- Use the **sidebar** radio buttons to switch between pages
- Click on chart elements for details
- Hover over data points for tooltips

### Interactive Features
- **Zoom**: Click and drag on charts
- **Pan**: Hold shift and drag
- **Reset**: Double-click chart
- **Filter**: Use dropdowns and multi-selects
- **Download**: Export tables as CSV

### Performance Tips
- Data is cached for speed
- First load may take a few seconds
- Subsequent page switches are instant
- Refresh browser to reload data from disk

## Customization

### Port Configuration
Default port is 8501. To change:

```bash
streamlit run dashboard_app.py --server.port 8502
```

### Network Access
To access from other devices on your network:

```bash
streamlit run dashboard_app.py --server.address 0.0.0.0
```

### Theme
Streamlit uses your system theme by default. To force dark mode:

```bash
streamlit run dashboard_app.py --theme.base "dark"
```

## Data Requirements

## Troubleshooting

### Dashboard won't start
```bash
# Reinstall Streamlit
pip install --upgrade streamlit

# Check for port conflicts
lsof -i :8501
```

### No data showing
```bash
# Run analysis first
python earnings_options_analytics.py --export-csv --export-charts

# Check CSV files exist
ls -la outputs/csv_reports/
```

### Charts not rendering
```bash
# Update Plotly
pip install --upgrade plotly

# Clear Streamlit cache
rm -rf ~/.streamlit/cache
```

### Slow performance
- Reduce dataset size by filtering strategies
- Close unused browser tabs
- Use `--quick` mode for faster analysis

## Advanced Usage

### Running in Production

For deployment on a server:

```bash
streamlit run dashboard_app.py \
  --server.port 8501 \
  --server.address 0.0.0.0 \
  --server.headless true \
  --server.enableCORS false
```

### Automated Updates

Set up a cron job to refresh data:

```bash
# Run analysis every day at 6 AM
0 6 * * * cd /path/to/earnings_options_analytics && python earnings_options_analytics.py --export-csv
```

### Integration with GitHub Actions

The dashboard can display data generated by GitHub Actions workflows:

1. Workflow exports CSV files
2. Commit to repository
3. Pull latest changes
4. Dashboard automatically shows new data
